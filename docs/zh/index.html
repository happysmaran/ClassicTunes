ClassicTunes

带回经典的 iTunes 体验

关于

ClassicTunes 是一款从零开始使用 Swift 和 SwiftUI 构建的现代 macOS 应用程序，在现代 Apple Silicon Mac 上忠实再现了 iTunes 7-10 的外观和体验。

  • 还原度极高的 Cover Flow
  • 迷你播放器 (MiniPlayer)
  • 播放列表和智能播放列表（支持智能 m3u）
  • Tunes Store（通过 iTunes API）
  • 歌词支持（使用 lrclib 或元数据）
  • iPod 同步 (1st-2nd gen Shuffles)
  • Discord Rich Presence (集成 MusicPresence)
  • 颜色与主题自定义
  • 经典的 iTunes 7-10 美学

系统要求：macOS 14 Sonoma 或更高版本，Apple Silicon（M 系列和 A 系列）。
