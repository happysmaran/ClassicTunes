ClassicTunes

クラシックなiTunes体験を再現

概要

ClassicTunesは、SwiftとSwiftUIを使用してゼロから構築された最新のmacOSアプリであり、最新の Apple Silicon Mac上でiTunes 7〜10の外観と操作性を忠実に再現しています。

  • 忠実に再現された Cover Flow
  • ミニプレーヤー
  • プレイリストとスマートプレイリスト (スマート m3u サポート付き)
  • Tunes Store (iTunes API 経由)
  • 歌詞のサポート (lrclib またはメタデータを使用)
  • アイポッドの同期 (1st-2nd gen Shuffles)
  • Discord Rich Presence (MusicPresence を使用)
  • カラーとテーマのカスタマイズ
  • クラシックな iTunes 7〜10 の美学

システム要件：macOS 14 Sonoma 以降、Apple Silicon（Mシリーズ／Aシリーズ）。
