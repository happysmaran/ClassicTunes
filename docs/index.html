ClassicTunes

Bringing back the classic iTunes experience

About

ClassicTunes is a modern macOS app built from scratch using Swift and SwiftUI, faithfully recreating the look and feel of iTunes 7-10 on modern-day Apple Silicon Macs.

  • Faithfully recreated CoverFlow
  • MiniPlayer
  • Playlists and Smart Playlists (with smart m3u support)
  • Tunes Store (via iTunes API)
  • Lyrics support (with lrclib or metadata)
  • iPod Syncing (1st-2nd gen Shuffles)
  • Discord Rich Presence (with MusicPresence)
  • Color and Theme Customization
  • Classic iTunes 7-10 aesthetics

System requirements: macOS 14 Sonoma or later, Apple Silicon (M-series and A-series Silicon).
